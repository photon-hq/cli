# Contributing

Please report bugs and request features through
[GitHub issues](https://github.com/photon-hq/cli/issues).

This repository is published from Photon's private CLI repository with each
release. External pull requests are not accepted: a change made here would be
overwritten by the next release. Every change, including dependency and
security updates, is made upstream and reaches this repository with the next
release. Maintainer pull requests change only the community files: the README,
LICENSE, this guide, `SECURITY.md` and `.github/`. Apart from those, `main`
changes only at releases.

Photon CLI 1.0 lives on the `legacy` branch.

Do not include credentials or private customer data in issues. Report security
problems privately as described in [SECURITY.md](SECURITY.md).
